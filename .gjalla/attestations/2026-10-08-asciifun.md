## Why
The owner asked for the functions of the ASCII repos (asciichart, asciigraph, ascii-art,
ASCII-Data, ascii-view, ascii-image-converter, cmatrix) inside Kate, which is to become
Misty, the base for the canvas work. Those repos are in Python/JS, Go, Rust, Java and C,
so each idea was rewritten in Kate's C++/Qt instead of copied in. The text logic lives in a
Qt-only library apart from the editor glue so it is testable without a running editor.
Matrix rain was written from scratch because cmatrix is GPL-3.
